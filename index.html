How it works

From job listing to cover letter in seconds.

Open the side panel on any job listing page and follow these steps.

01

Upload your CV

Drop in your CV as a .md or .txt file. Your name is extracted automatically.

02

Extract the job description

Click "Extract from page" to pull the job description automatically, or paste it manually.

03

Generate

Hit Generate and watch your cover letter stream in, powered by your local Ollama model.

04

Copy & send

Copy the finished letter to your clipboard and paste it wherever you need it.

Features

Built for privacy and control.

Fully local

Runs on Ollama — your data never touches an external server.

Any Ollama model

Pick any model you have installed — llama3.2, mistral, and more.

Auto page extraction

Pulls job descriptions from any page — including LinkedIn.

Custom instructions

Add tone, length, or style instructions to tailor every letter.

Installation

Get set up in a few minutes.

1

Install Ollama from ollama.ai and pull a model.

ollama pull llama3.2
2

Run the Ollama service with custom origins:

OLLAMA_ORIGINS=chrome-extension://* ollama serve

Then restart Ollama.

3

Download and load the extension.

Download the zip, unzip it, then open chrome://extensions, enable Developer Mode, and click Load unpacked.
